# 书库文本复制与批量传输设计

## 目标

让书库中的作者、JM 号和作品名可以直接选中复制，并让用户在批量管理模式下把多本漫画 PDF 快速交给电脑 QQ：默认复制 PDF 文件到 Windows 剪贴板，用户在 QQ 聊天窗口按 `Ctrl+V` 发送；同时提供 ZIP 打包以便拖拽或作为备用传输方式。

## 设计

- 书库作者分组标题和作品卡片底部标题使用可选中的文本标签，保留现有字体和布局；文本复制由 Qt 的文本交互标志处理。
- 新增 `share_service.py`，负责从 `AlbumRecord` 筛选存在的 PDF、构造剪贴板文件 URL、清理 ZIP 文件名并生成 ZIP。UI 不直接处理压缩细节。
- 批量栏新增“复制 PDF”和“打包 ZIP”。“复制 PDF”使用 `QMimeData.urls` 写入系统剪贴板，默认作为主要按钮；“打包 ZIP”弹出保存对话框，默认文件名包含当前日期时间。
- 缺失 PDF 会跳过并显示数量；没有可用 PDF 时不修改剪贴板，也不创建 ZIP。
- ZIP 内文件名为 `JM号-作品名.pdf`，非法字符替换为下划线，同名文件追加编号。

## 测试

- 服务层测试覆盖有效/缺失 PDF 筛选、ZIP 内容、重名和安全文件名、剪贴板 URL 列表。
- 书库 UI 测试覆盖作者/作品文本的文本交互标志，以及批量按钮默认状态和调用服务。
- 运行现有桌面端测试集合、相关模块 `py_compile` 和 `git diff --check`。

## 范围

不自动操控 QQ 窗口、不调用 QQ 私有接口、不上传网络；不改变现有删除、搜索、分类和 PDF 打开行为。
