# 书库封面液态玻璃与透视倾斜设计

## 目标

让书库页的封面卡片在鼠标悬停时呈现「液态玻璃 + 随鼠标透视倾斜」的质感，同时不改变点击打开 PDF、右键菜单、文本选中复制和批量管理等既有行为。

## 设计

- 新增 `src/jmcomic_shelf/ui/glass_cover.py`，提供 `GlassCoverView(QWidget)`，只负责把一张封面图渲染成可倾斜的玻璃瓦片，不接触数据与交互逻辑；模块级 `dip_quad` / `perspective_transform` 是透视数学。
- `CoverCard` 的封面控件从 `QLabel` 换成 `GlassCoverView`；标题仍是可选中复制的 `CaptionLabel`，固定在封面下方，完全不参与倾斜。原因：自绘的倾斜文字会被卡片边界裁掉，倾斜到某些角度会被遮住，所以动效只保留在封面瓦片上。
- 瓦片尺寸：封面 150×210，四周留 9px 绘制留白（控件 168×228），用于阴影、辉光和倾斜溢出，避免被网格裁切；`CoverCard.card_width` 保持 178，卡片内边距改为 5px，使瓦片在卡片里居中。
- 状态由动画驱动：`hoverProgress`（0→1，进场 160ms `OutCubic`，出场 220ms `OutCubic`）、指针归一化坐标（−1→1，鼠标移动时 140ms `OutQuad` 追随，形成「液态拖尾」）。
- 透视：最大倾角 6°，用 `QTransform.quadToQuad` 把瓦片贴图映射到四个投影角点；近鼠标角向屏幕内侧下压，对角微微抬起。鼠标在左上时左上角内压；整体方向由常量 `TILT_DIRECTION` 控制，必要时一个符号即可翻转。
- 悬停抬升：以瓦片中心为原点放大 1.03；卡片背景框和下方标题都保持平面不动。
- 封面卡片本身不带底板和实线外框：`CoverCard.paintEvent` 不调用 `CardWidget.paintEvent`，并用 `COVER_CARD_STYLE` 覆盖页面样式表里的 `CardWidget` 规则，否则悬停倾斜时外侧会出现一个不跟着动的方框。批量选中反馈由 `_draw_selection` 自绘青色描边和极淡底色。
- 绘制分三层：圆角封面 + 静态玻璃底缓存为 `QPixmap`（仅在尺寸、主题或封面变化时重建）；透视贴图；跟随指针的径向高光、青色 `#00c8d7` 内缘辉光和柔和投影。玻璃叠层只在悬停时出现，静止状态与原来一致。
- 投影必须是模糊剪影（`_shadow_pixmap` 生成、`_draw_shadow` 绘制），不能沿瓦片轮廓描边：描边在浅色主题下会变成跟着倾斜的硬边灰线。投影在瓦片坐标系里绘制并裁剪到瓦片外侧，封面未填满瓦片时不会压暗留白；边缘高光渐变终点为全透明，不能以灰色收尾。
- 不做真实背景模糊：Qt 滚动网格里抓取背景再模糊会掉帧，深色 Fluent 底几乎看不出差别，玻璃感由叠层与高光模拟。
- 主题：按 `isDarkTheme()` 分支，深色用白高光与深投影，浅色降低高光强度、加深描边。

## 边界

- 只有鼠标进入封面瓦片才触发；悬停卡片标题区不触发。标题始终是静态标签，随时可以选中复制。
- 滚动或窗口缩放导致卡片重建时，悬停状态随控件销毁复位。
- 无封面时沿用「无封面」占位文案，同样套玻璃底板。
- 批量管理模式的复选框、勾选描边、点击打开 PDF、右键菜单和文本选中复制行为不变。
- 只有被悬停的那一张卡片重绘，其余卡片完全静态。

- 新增 `tests/test_jmcomic/test_shelf_glass_cover.py`：倾斜方向（近鼠标角内压、对角外扩）、指针归一化裁剪、悬停动画的终值与时长、离屏渲染有非透明像素且倾斜后画面变化、无封面占位、`CoverCard.cover` 类型与尺寸、悬停时标题保持平面且样式不变、无底板外框、选中时自绘青色描边。
- 回归：`test_shelf_*.py` 全量、相关 `py_compile`、`git diff --check`。
- 视觉验证：离屏脚本渲染常态与四个角的悬停状态，人工核对后再交付。

## 范围

只做书库页封面卡片。不改详情页封面，不改数据层，不引入第三方依赖，不做真实背景模糊，不新增设置项。
